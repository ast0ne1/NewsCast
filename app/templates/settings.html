Reader

Xteink needs CrossPoint. Add this copy’s OPDS catalog there. Push uses HTTP File Transfer.

Kobo needs KOReader. Add the same OPDS catalog in KOReader (File browser → magnifying glass → OPDS catalog). Push uses SSH/SFTP over Wi-Fi instead of CrossPoint’s HTTP upload.

Leave this off. CrossPoint can crash if the catalog asks the reader to log in. The catalog stays open on your LAN.

KOReader supports HTTP Basic. Leave this off on a trusted LAN.

Sync

The same reader can sync with this copy and another (home Pi or work laptop). Change the device host to that copy’s URL. Instance name on General labels the briefing so you know which one you pulled.

{% if reader_ssh_password.set %}Password saved ({{ reader_ssh_password.hint }}). Leave blank to keep it.{% else %}Optional. Leave blank if KOReader has “Login without password” on.{% endif %}

In KOReader: Tools (cog) → Network → SSH server, port 2222. Keep Wi-Fi on while NewsCast pushes.

Files land in a personal subfolder on the device (for example {{ reader_upload_path }}) so household accounts do not mix.

KOReader’s file browser root is /mnt/onboard. Default base folder is /mnt/onboard/News.

NewsCast checks your CrossPoint host every minute. If File Transfer is on, queued briefing and Send files upload to your folder. If the reader is asleep, they wait.

NewsCast checks your Kobo SSH port every minute. If KOReader’s SSH server is running, queued files copy over SFTP. If SSH is off or the Kobo is asleep, they wait.
